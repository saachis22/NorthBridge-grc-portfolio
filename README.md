# ISO 27001 GRC Portfolio — NorthBridge Health Analytics

A self-directed GRC portfolio project simulating an ISO/IEC 27001:2022
readiness assessment for a fictional healthcare SaaS organization.

> Disclaimer
> NorthBridge Health Analytics is a fictional organization created for
> educational and portfolio purposes. No real organization, employees,
> systems, or data are represented.

## Project Overview

NorthBridge Health Analytics is a fictional healthcare SaaS company that
processes Protected Health Information (PHI) and operates primarily in AWS.

The organization is beginning its first formal information security
management program after a hospital customer requested evidence of
alignment with ISO/IEC 27001.

## Objectives

- Identify and assess information security risks
- Develop a risk treatment approach
- Assess controls against ISO/IEC 27001:2022 Annex A
- Develop an Information Security Policy
- Create a Statement of Applicability
- Document internal audit findings
- Map controls across security frameworks
- Communicate findings to leadership

## Frameworks & Regulations

- ISO/IEC 27001:2022
- NIST Cybersecurity Framework
- HIPAA/HITECH

The assessment identified significant gaps in areas including:

- Incident response
- Access governance
- Security monitoring
- Vendor risk management
- Security awareness
- Vulnerability management
- Secure development
